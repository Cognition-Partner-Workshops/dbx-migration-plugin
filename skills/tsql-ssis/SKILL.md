# T-SQL + SSIS Dialect (v1)

## When to use / routing

Source-side half of the factory for the Lakebridge `mssql` and `ssis` flags. Sybase ASE 16 is a sub-profile (Lakebridge has no ASE flag): apply the rows marked **ASE** by hand before and after the transpile. Fixture: `Cognition-Partner-Workshops/ts-tsql-sybase-legacy-db` (loan servicing; no SSIS, so the SSIS example is a hand-written `.dtsx`-shaped package).

Everything Databricks-side is a pointer through `skills/target-routing/SKILL.md` to the official plugin; this file never restates it:

## Type map

`Delta` is the analytical track, `Lakebase PG` the OLTP front door. `canon` = harness rule in `canonicalization.json`; `GAP` = not in the harness (PR body).

| Source | Delta | Lakebase PG | Loss / canon |
|---|---|---|---|
| `BIT` | `BOOLEAN` | `BOOLEAN` | 0/1/'TRUE' accepted in source; Tier 2 null-rate |
| `TINYINT` (0..255) | `SMALLINT` (Delta `TINYINT` is signed) | `SMALLINT` | none |
| `SMALLINT` / `INT` / `BIGINT` | same | `SMALLINT` / `INTEGER` / `BIGINT` | none |
| `INT IDENTITY` | `BIGINT GENERATED BY DEFAULT AS IDENTITY`: `INSERT` the source keys, then `ALTER TABLE t ALTER COLUMN id SYNC IDENTITY` before the first generated insert (`GENERATED ALWAYS` rejects explicit values; identity columns disable concurrent writes, so tables written by concurrent `BEGIN ATOMIC` callers get plain `BIGINT` + a generated surrogate elsewhere) | `BIGINT GENERATED BY DEFAULT AS IDENTITY`; `setval(pg_get_serial_sequence(...), max(id))` after load | source keys preserved, so FK/Tier 3 recon keys on them; `identity` |
| `DECIMAL(p,s)` / `NUMERIC` | `DECIMAL(p,s)` | `NUMERIC(p,s)` | exact: `identity` at any scale; a recomputed column is `cast(... AS DECIMAL(p,s))` in the converted SQL, never `decimal_round` (places=4 would equate values differing in digit 5+) |
| `MONEY` / `SMALLMONEY` | `DECIMAL(19,4)` / `DECIMAL(10,4)` | `NUMERIC(19,4)` / `(10,4)` | loaded: `identity`; source rounds every operation to 4 places, so only columns the target recomputes from `MONEY` get `decimal_round` places=4 `half_up` |
| `FLOAT` / `REAL` | `DOUBLE` / `FLOAT` | `DOUBLE PRECISION` / `REAL` | relative tolerance in the tolerance record |
| `CHAR(n)` | `STRING` (or `STRING COLLATE UTF8_BINARY_RTRIM`) | `CHAR(n)` | blank padding; `rstrip_spaces` |
| `VARCHAR(n)` / `NVARCHAR(n)` / `NCHAR(n)` | `STRING` | `VARCHAR(n)` / `TEXT` | CI collation; `collation_casefold` when census says `_CI_`, plus `rstrip_spaces` |
| `VARCHAR(MAX)` / **ASE** `TEXT` / `UNITEXT` | `STRING` | `TEXT` | ASE `TEXT` not comparable in source: Tier 2 `length()`/hash only |
| `BINARY` / `VARBINARY` / **ASE** `IMAGE` | `BINARY` | `BYTEA` | Tier 2 `octet_length`, `sha2` |
| `ROWVERSION` / `TIMESTAMP` | drop or load-time `BINARY` | `BYTEA` | engine-assigned; exclude from recon |
| `DATE` / `SMALLDATETIME` | `DATE` / `TIMESTAMP_NTZ` | `DATE` / `TIMESTAMP` | none |
| `DATETIME` (**ASE** too) | `TIMESTAMP_NTZ` | `TIMESTAMP` | 1/300 s grid (`.000/.003/.007`) is exact in µs: loaded columns `identity`; only columns the target recomputes at ms/µs (`DATEADD`, arithmetic) use `datetime_grid_333` (10 ms grid, equates `.000/.003` -> tolerance record; exact fit is `GAP: datetime_tolerance_ms`) |
| `DATETIME2(p)` / `TIME(p)` / **ASE** `BIGDATETIME` | `TIMESTAMP_NTZ` / `TIME` | `TIMESTAMP` / `TIME` | p <= 6 exact: `identity`; p = 7 loses the 100 ns digit: extract the source at µs the way the loader did (`LEFT(CONVERT(VARCHAR(27),x,121),26)`), `GAP: datetime_truncate_us`; never `datetime_utc_truncate_ms` (hides µs) |
| `DATETIMEOFFSET(p)` | `TIMESTAMP` (UTC-normalised) | `TIMESTAMP WITH TIME ZONE` | offset lost: keep `offset_minutes` if read; p <= 3 `datetime_utc_truncate_ms` (UTC-normalises, lossless at ms); p > 3 normalise in the extraction (`SWITCHOFFSET(x,'+00:00')`) then as `DATETIME2(p)` |
| `UNIQUEIDENTIFIER` | `STRING` (36-char) | `UUID` | upper vs lower case; `uuid_normalize` |
| `XML` / `SQL_VARIANT` | `STRING` (+ type tag) | `XML` / `TEXT` | `GAP: xml_canonicalize`, `GAP: variant_split` |
| `HIERARCHYID` / `GEOGRAPHY` / `GEOMETRY` | `STRING` / `GEOGRAPHY(srid)` / `GEOMETRY(srid)` | `TEXT` / PostGIS | hand-convert |
| TVP / `CURSOR` variable / **ASE** `UNSIGNED INT` | temp table or `ARRAY<STRUCT>` / rewrite / `BIGINT` | n/a / n/a / `BIGINT` | signature change |

## Function and construct map

| Source | Databricks SQL | Note |
|---|---|---|
| `ISNULL(a,b)` | `coalesce(a,b)` | source truncates `b` to `a`'s type (`ISNULL(char(2),'UNKNOWN')`=`'UN'`); `isnull(x)` is a boolean test |
| `IIF` / `CHOOSE` / `NULLIF` | `iff` / `elt` / `nullif` | `elt` raises out of range where `CHOOSE` returns NULL |
| `a + b` (strings) / `CONCAT` | `a \|\| b` / `concat(coalesce(a,''),...)` | SQL Server NULL yields NULL; **ASE** and `CONCAT` treat NULL as `''`: wrap in `coalesce(x,'')`; numbers need `cast(... AS STRING)` |
| `LEN(s)` / `DATALENGTH(s)` | `length(rtrim(s))` / `NVARCHAR`,`NCHAR`: `octet_length(encode(s,'UTF-16LE'))`; `VARCHAR`,`CHAR`: `octet_length(encode(s,'ISO-8859-1'))` for any single-byte page incl. 1252 (count only, bytes may differ), `octet_length(s)` only for `_UTF8` collations or ASCII-only data, else hand-convert | `LEN` ignores trailing spaces; `DATALENGTH` counts source bytes (UTF-16 or the code page), `octet_length(s)` counts UTF-8 bytes |
| `CHARINDEX` / `PATINDEX` | `charindex` / `regexp_instr` | wildcard pattern -> regex; collation-sensitive in source |
| `SUBSTRING(s,start,len)` | `substring(s,start,len)` | negative `pos` counts from the end on Databricks; `len` mandatory in T-SQL |
| `LEFT` / `RIGHT` (n<0) | `CASE WHEN n<0 THEN raise_error(...) ELSE left(s,n) END` | source raises, Databricks returns `''` |
| `STUFF(s,start,len,new)` | `CASE WHEN start<1 OR start>length(s) OR len<0 THEN NULL ELSE overlay(s PLACING coalesce(new,'') FROM start FOR least(len,length(s)-start+1)) END`; `BINARY` `s`: `coalesce(new, cast('' AS BINARY))`, and a character `new` is first re-encoded the way the source did (`encode(new,'UTF-16LE')` for `NVARCHAR`, code page 1252 (`Latin1_General_*` `VARCHAR`) is not an `encode` charset: `encode(translate(new, '€‚ƒ„…†‡ˆ‰Š‹ŒŽ‘’“”•–—˜™š›œžŸ', <the 27 code points U+0080..U+009F 1252 assigns them, in that order>), 'ISO-8859-1')`, since ISO-8859-1 emits U+0080..U+009F as bytes 0x80..0x9F, so the result is byte-identical to 1252 for every 1252-representable string; other code pages hand-convert) | `STUFF(s,i,n,NULL)` deletes; `overlay` with NULL `replace` returns NULL, hence `coalesce`, typed like `s` (`overlay` needs same-type operands, SQL Server implicitly converts character `new` to binary); bare `overlay` only for literal in-range non-NULL args |
| `REPLICATE(s,n)` | `CASE WHEN n<0 THEN NULL ELSE repeat(s,n) END`; where the non-MAX 8,000-**byte** cap mattered: `left(...,8000)` for single-byte `VARCHAR`, `left(...,4000)` for `NVARCHAR`, multibyte code pages hand-convert | Databricks never truncates |
| `LTRIM`/`RTRIM`/`TRIM`/`UPPER`/`LOWER`/`REVERSE`/`SPACE` | same names | `UPPER` locale-aware in source; Tier 3 on non-ASCII keys |
| `REPLACE` / `TRANSLATE` | `replace` / `translate` | source matches under CI collation; `TRANSLATE` length mismatch errors in T-SQL, deletes in Databricks |
| `ASCII`/`CHAR`/`UNICODE`/`NCHAR` | `ascii` / `char` / `conv(hex(encode(left(c,1),'UTF-16BE')),16,10)` / `decode(unhex(lpad(hex(n),4,'0')),'UTF-16BE')` | `char`/`chr` wrap modulo 256; supplementary chars hand-convert |
| `STRING_AGG ... WITHIN GROUP` / `STRING_SPLIT` | `string_agg ... WITHIN GROUP` / `explode(split(s, regex))` | always add `WITHIN GROUP (ORDER BY)` before Tier 3; `split` takes a regex |
| `FORMAT(v,'fmt')` / `QUOTENAME(s[,q])` | `format_number` / `date_format` / `to_char`; value: `CASE WHEN length(s)>128 THEN NULL ELSE o \|\| replace(s,c,c\|\|c) \|\| c END` with `o`/`c` the literal open/close pair for `q` (default `[`/`]`; `(`/`)`, `{`/`}`, `<`/`>`; `'`, `"`, `` ` `` close with themselves, e.g. `'''' \|\| replace(s,'''','''''') \|\| ''''`); any other `q` is NULL in source; only when the result is spliced into dynamic SQL as a name: delimit with backticks, doubling any backtick in `s` (docs `sql-ref-identifiers`), or pass the raw name to `IDENTIFIER(:s)` | .NET formats and culture have no equivalent; rewrite each literal. `QUOTENAME` is a string function (NULL in -> NULL out): `IDENTIFIER()` on a value expression resolves it as an object name |
| `LIKE '[a-f]%'` | `rlike` | bracket classes are not SQL `LIKE` |
| `s1 = s2` under `_CI_AS` / `COLLATE x` | `COLLATE UTF8_LCASE` (`_CI_AS`), `UNICODE_CI_AI` (`_CI_AI`) | decide once per table; mixing explicit collations is an error |
| `GETDATE()` / `GETUTCDATE()` / `SYSDATETIME()` | `current_timestamp()` (store `TIMESTAMP_NTZ`; `from_utc_timestamp(...,'<server tz>')` if local time was assumed) | 3.33 ms grid / 100 ns vs µs |
| `DATEADD(part,n,d)` | `dateadd(PART,n,d)` / `add_months` | returns `TIMESTAMP`: cast back to `DATE` |
| `DATEDIFF(day,a,b)` | `datediff(b,a)` (dates only) | argument order reversed |
| `DATEDIFF(month/year/hour,a,b)` | `(year(b)*12+month(b))-(year(a)*12+month(a))` / `year(b)-year(a)` / `floor(unix_timestamp(b)/3600)-floor(unix_timestamp(a)/3600)` | T-SQL counts boundary crossings, `timestampdiff` counts elapsed units |
| `DATEPART(week)` / `DATENAME` / `EOMONTH` / `DATEFROMPARTS` | `extract(WEEK)` (ISO) / `date_format(d,'EEEE'\|'MMMM')` / `last_day(add_months())` / `make_date` | T-SQL week is `DATEFIRST`-dependent; `dayname` is 3-letter |
| `CONVERT(VARCHAR,d,style)` | `date_format(d,pattern)`: 101 `MM/dd/yyyy`, 103 `dd/MM/yyyy`, 104 `dd.MM.yyyy`, 106 `dd MMM yyyy`, 108 `HH:mm:ss`, 112 `yyyyMMdd`, 120 `yyyy-MM-dd HH:mm:ss`, 121 `... .SSS`, 126 `yyyy-MM-dd'T'HH:mm:ss.SSS`, 100/109 (**ASE** default) `MMM dd yyyy hh:mma` | two-digit-year styles 1..14 are a trap |
| `CONVERT(DATETIME,s,style)` / `CAST` / `TRY_CAST` | `to_timestamp(s,pattern)` / `cast` / `try_cast` | always pass the pattern; `CAST(x AS VARCHAR)` truncates to 30 in T-SQL |
| `ROUND(x,n)` / `ROUND(x,n,1)` | `round(x,n)` / `CASE WHEN x<0 THEN ceil(x,n) ELSE floor(x,n) END` | truncation is toward zero; a bare `floor` is one unit low on negatives |
| `a / b` (ints) / `x / 0` | `a div b` / `try_divide` | `/` returns `DOUBLE`; `-7/2` = `-3` in T-SQL |
| `%` / `POWER` / `LOG(x,base)` | `%` / `power` / `log(base,x)` | `POWER(int,int)` overflows in T-SQL |
| `CHECKSUM` / `HASHBYTES` | `hash` / `sha2` | different algorithms/encodings: recompute both sides from canonical text |
| `SUM(INT)` / `AVG(INT)` / `AVG(MONEY)` | `sum` / `sum(c) div count(c)` / `avg` + `round(...,4)` | `AVG(INT)` truncates toward zero; `avg(DECIMAL)` widens scale |
| `STDEV`/`VAR` / `PERCENTILE_CONT` / ranking and `LAG`/`LEAD` | `stddev_samp`/`var_samp` / `percentile_cont` / same | |
| `TOP (n)` / `WITH TIES` / `PERCENT` / `OFFSET n ROWS FETCH NEXT m` | `LIMIT n` / `QUALIFY rank() OVER (ORDER BY k) <= n` / `QUALIFY row_number() OVER (ORDER BY k) <= ceil(count(*) OVER () * n/100.0)` / `LIMIT m OFFSET n` | `TOP (@n)` -> `EXECUTE IMMEDIATE` or `row_number()` filter; make `ORDER BY` deterministic |
| `SELECT ... INTO #t` / `DECLARE @t TABLE` | `CREATE TEMP TABLE t AS SELECT ...` | session-scoped; no `CREATE OR REPLACE`, no `DELETE FROM` |
| **ASE** `FROM a, b WHERE a.k *= b.k [AND b.x = 'A']` | `FROM a LEFT JOIN b ON a.k = b.k AND b.x = 'A'` | ASE evaluates inner-table qualifications as part of the join: rows of `a` whose `b` rows all fail `b.x = 'A'` are kept null-supplied, never dropped, so `ON` is the exact rewrite and `WHERE` is not (`examples/view-outer-join`) |
| `UPDATE t SET ... FROM t JOIN s` / `DELETE t FROM ...` | `MERGE INTO t USING s ... WHEN MATCHED THEN UPDATE/DELETE` | 1:N picks an arbitrary row in T-SQL, raises in `MERGE`: dedupe first; `OUTPUT` -> separate count query |
| `SCOPE_IDENTITY()` / `@@IDENTITY` (**ASE** only `@@identity`) | read the key back by business key / `run_key` | trigger-hijackable in source; keys loaded, not regenerated |
| `@@ROWCOUNT` / **ASE** `SET ROWCOUNT n` loops | one `UPDATE` with the full predicate, then `GET DIAGNOSTICS n = ROW_COUNT` (DBR 18 LTS+ / DBSQL) | a pre-computed `count(*)` is another snapshot, not the row count |
| `@@ERROR` + `GOTO err` / `TRY ... CATCH` | `DECLARE EXIT HANDLER FOR SQLEXCEPTION BEGIN ... END;` (`RESIGNAL` to re-raise) | `EXIT` handlers only: a swallowing `CATCH` becomes a nested block with its own handler |

| `CREATE PROCEDURE p @a INT, @b MONEY OUTPUT ... RETURN n` | `CREATE OR REPLACE PROCEDURE p(IN p_a INT, OUT p_b DECIMAL(19,4), OUT p_rc INT) LANGUAGE SQL SQL SECURITY INVOKER AS BEGIN ... END;` | prefix params `p_`: a bare name resolves as a column first |
| `SELECT @v = col FROM ...` (N rows) / `SET @v = (SELECT ...)` | `SET v = (SELECT col ... ORDER BY k LIMIT 1)` / `SET (a,b) = (SELECT x,y ...)` | last-row-wins in source; >1 row raises in Databricks |

| Scalar UDF / TVF | `CREATE FUNCTION ... RETURN <expr>` or inline / view | |

## Traps with recon signature

| Trap | Recon signature | Fix / decision |
|---|---|---|
| **ASE `*=` with inner-side WHERE predicate** | Tier 1 count < source; Tier 2 null-rate on the outer columns = 0 | predicate into `ON`, not `WHERE` (`examples/view-outer-join`); Lakebridge mangles `*=` |
| **`DATETIME` 1/300 s grid** | Tier 3 on `DATEADD`/arithmetic columns recomputed on the target; Tier 2 `max()` drift <= 3 ms | loaded values compare exactly (`identity`); recomputed columns `datetime_grid_333` with the 10 ms grid in the tolerance record |
| **CI collation equality/grouping** (`_CI_AS`; **ASE** default is binary, check `sp_helpsort`) | Tier 2 distinct-count drift on string keys; Tier 1 on string joins | `COLLATE UTF8_LCASE`, never `lower()` in joins; `collation_casefold` only when the census reports CI |
| **Trailing-space padding** (`CHAR(n)`, `ANSI_PADDING`) | Tier 2 distinct-count on `loan_type`-style codes; joins fan out to 0 | `rtrim()` on load or `UTF8_BINARY_RTRIM`; `rstrip_spaces` |
| **`ISNULL` type coercion** | Tier 2 `max(length())` drift | reproduce the truncation or record the fix in the tolerance record |
| **`@@ROWCOUNT` / `SET ROWCOUNT` batching** | Tier 1 on the target after the run; `audit_trail.record_count` = rows updated | single `UPDATE` + `GET DIAGNOSTICS ROW_COUNT`; no pre-materialised target list |
| **Integer division / `AVG(INT)`** | Tier 2 drift on ratio columns, one unit on negatives with `floor` | `div`, `sum() div count()` |
| **`MONEY` arithmetic** | Tier 2 sums differ in the 5th+ decimal | `round(...,4)` at each source rounding step; `decimal_round` places=4 on those columns only |
| **`DATEDIFF` boundaries** | Tier 2 histogram drift on `days_past_due` buckets | rewrite per the map |
| **`CONVERT` style codes** (**ASE** default 100) | Tier 3 on formatted strings | pattern table in the map |
| **`@@identity` hijacked by triggers** | Tier 3 on FKs populated from it | business-key read-back; `identity` |
| **NULL concatenation** (**ASE** `NULL + 'x'` = `'x'`) | Tier 2 null-rate rises on `action_detail`-style columns | `coalesce(x,'')` per operand; `null_missing_equiv` is not the fix |
| **`SELECT @v = col` over N rows** | procedure raises, or Tier 3 diff on the derived value | deterministic `ORDER BY ... LIMIT 1` |
| **Parameter shadowing** (`@servicer_id` -> `servicer_id`) | Tier 1 count too high; wrong `batch_id` in Tier 3 | `p_` prefix, aliases on every column |
| **Multi-table transaction flattened to sequential DML**, or check racing its DML | clean run passes every tier; failure-injection and concurrent-writer replays fail | `BEGIN ATOMIC` on catalog-managed tables, else compare-and-set; per-row -> per-batch commit unit recorded per unit |
| **SSIS Lookup cache mode vs collation** | Tier 1 matched/no-match counts | `UTF8_BINARY` join for Full cache, `UTF8_LCASE` for no-cache |
| **Per-run SSIS parameter as a streaming table** | permanent false no-match rows after a parameter change | bounded batch (`examples/ssis-dataflow-lookup`) |
| **`UNIQUEIDENTIFIER` case** / **`DATETIME` zone** | Tier 3 100% key mismatch / Tier 2 `min()/max()` shifted | lower-case on load, `uuid_normalize` / land as `TIMESTAMP_NTZ`, tolerance record names the server zone |

## Canonical Lakeflow / DBSQL shape

Procedure (T-SQL cursor + `GOTO` + `RAISERROR` + `@@identity`; full form in `examples/proc-cursor-payments/converted.sql`):

```sql
CREATE OR REPLACE PROCEDURE ${catalog}.${schema}.p(IN p_date TIMESTAMP_NTZ, IN p_servicer_id INT, OUT p_rc INT)
LANGUAGE SQL SQL SECURITY INVOKER
AS BEGIN
    DECLARE run_key STRING DEFAULT uuid();
    DECLARE failed CONDITION FOR SQLSTATE '45001';                 -- RAISERROR 50001
    DECLARE EXIT HANDLER FOR SQLEXCEPTION                          -- error_handler:
    BEGIN DROP TABLE IF EXISTS work; SET p_rc = 1;
          SIGNAL failed SET MESSAGE_TEXT = 'failed for run ' || run_key; END;
    SET p_rc = 0;
    CREATE TEMP TABLE work AS SELECT ... FROM t WHERE t.servicer_id = p_servicer_id;   -- SELECT INTO #t
    BEGIN ATOMIC                                                   -- BEGIN TRAN ... COMMIT across tables
        INSERT INTO ${catalog}.${schema}.child SELECT ... FROM work;
        IF EXISTS (SELECT 1 FROM ${catalog}.${schema}.parent t JOIN work w ON ... WHERE <trigger check>) THEN
            SIGNAL SQLSTATE '45050' SET MESSAGE_TEXT = '<trigger message>';   -- ROLLBACK TRIGGER
        END IF;
        MERGE INTO ${catalog}.${schema}.parent t USING work w ON t.k = w.k WHEN MATCHED THEN UPDATE SET ...;
    END;
    DROP TABLE IF EXISTS work;
END;
```

## Canonicalization

`canonicalization.json` (loads with `recon.config.load_canon_rules`): `datetime_grid_333` (only `DATETIME` columns the target recomputes; loaded `DATETIME`/`SMALLDATETIME`/`DATETIME2(<=6)`/`BIGDATETIME` are exact in µs and use `identity`), `datetime_utc_truncate_ms` (only `DATETIMEOFFSET(<=3)`, where ms truncation is lossless), `collation_casefold` (only when the census reports `_CI_`), `rstrip_spaces` (`CHAR`), `decimal_round` places=4 `half_up` (only columns recomputed from `MONEY`; `DECIMAL(p,s)` of any scale is `identity`), `uuid_normalize`, `null_missing_equiv`, `identity`. `empty_string_is_null` is deliberately absent (would hide the ASE concatenation trap). The harness applies a rule only to fields whose mapping-spec `rules` list names it (`recon.config` field mapping), so `applies_to` / `enabled_if` are instructions for writing that list, not runtime switches.
